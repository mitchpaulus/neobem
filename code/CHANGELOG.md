# Changelog

## 0.1.0

- Initial release.
- Syntax highlighting for Neobem (`.bemp`, `.nbem`) ported from the Vim syntax
  file, including EnergyPlus IDF object types, Neobem language keywords,
  strings, comments, and DOE-2 constructs.
- Language server integration (`nbem --lsp`) providing hover, go to definition,
  find references, and field/key completion.
